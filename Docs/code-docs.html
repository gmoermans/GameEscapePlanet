BP_MapGenerator

Core · extends Engine.Actor

Level generator placed in / spawned for each map. Server picks (or reads from the URL option 'Seed') a replicated seed, spawns the ship at the origin, spawns replicated matter sources, and every machine generates the non-replicated decor (trees, rocks, plants) locally from the same seed. Projects spawn points onto the ground with a trace.

BP_Extractor

Tools · extends BP_Tool.BP_Tool

Matter extractor tool. Locks the nearest matter source(s) in range and moves matter into the player's carried stock each tick. Upgrades with TotalMatterExtracted: every UpgradeStep (200) gives +30% rate, +30% range and +10 player max matter; at 1000 it extracts from 2 sources at once. Shows its stats on the HUD and loops extract.wav while working.
